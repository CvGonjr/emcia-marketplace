# Pacote operacional controlado do método

Esta pasta é a cópia versionada dos documentos oficiais necessários para
executar as habilidades do `eiac-campo`. A origem de verdade permanece em
`artefatos/solucao/metodo S1/docs md`; `manifesto.json` fixa os SHA-256 da
versão empacotada.

O pacote vive no campo porque o campo é o método. O controle de contraste apenas
recebe um vínculo para esta pasta ao abrir uma execução; nenhum documento é
copiado para `emcia-contraste`.

Atualização exige copiar novamente a fonte controlada, recalcular o manifesto,
subir a versão do `eiac-campo` e executar `testes/metodo_empacotado.py`.
