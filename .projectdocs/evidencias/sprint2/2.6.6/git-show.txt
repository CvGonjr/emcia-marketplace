    fix(field): allow agent authorship of calibration cycle records
    
    calibragem.py::checar_autoria() blocked declarado_por/registrado_por
    from being an agent for both rotina_calibragem and ciclo_calibragem,
    contradicting the module's own documented contract ("o agente pode
    preparar um ciclo inteiro"). Only the decisao field should be
    human-only, already enforced separately by checar_decisao().
    
    Split into checar_autoria() (rotina, unchanged: always human) and
    checar_autoria_ciclo() (ciclo: authorship open to agents, decision
    still gated). Found while building the 2.6.6 control case, which is
    the first to exercise an agent-authored calibration cycle end to end;
    2.6.3's fixtures always defaulted declarado_por/registrado_por to a
    human name even when passing an agent as --ator.
